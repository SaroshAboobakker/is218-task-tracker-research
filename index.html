IS218 · CREATIVE PROJECT

Personal Task & Study Tracker

Exploring how a simple web application can help college students organize assignments, manage deadlines, and track their academic progress.

Explore the Research

01 · RESEARCH QUESTION

What Am I Trying to Understand?

How can a small web application help college students organize coursework and study tasks while keeping each user's records private and secure?

The intended audience is college students who want a better way to manage assignments, study sessions, and upcoming deadlines.

02 · CONCEPT COMPARISON

Two Ideas I Considered

Private Group Chat

A private messaging website for four users to communicate and save conversations.

Challenges

  • Keeping conversations private
  • Saving messages correctly
  • Supporting real-time messaging
Selected Concept

Task & Study Tracker

A website where students can create tasks, set deadlines, mark work as complete, and view their progress.

Challenges

  • Connecting tasks to the correct user
  • Protecting private information
  • Organizing tasks in a useful dashboard

I selected the task tracker because it solves a practical problem for students and gives me an opportunity to research databases, user accounts, and application security.

03 · USER STORIES

What Should the Website Do?

01

Create an Account

As a student, I want to register and log in so I can access my personal tasks.

02

Create Tasks

As a student, I want to add assignments and due dates so I can plan my work.

03

Manage Tasks

As a student, I want to edit, complete, or delete tasks when my plans change.

04

View Progress

As a student, I want a dashboard showing my tasks so I can understand my progress.

05

Manage My Account

As a student, I want to manage my account and sign out to protect my information.

04 · TECHNOLOGY

Planned Technology Stack

HTML

Creates the structure and content of the website.

CSS

Controls the website's layout, colors, and design.

JavaScript

Adds interactive features and handles user actions.

Supabase Auth

Handles user registration and login.

PostgreSQL

Stores task information in a database.

Row Level Security

Helps make sure users can only access their own records.

These technologies are planned for the application. The working application has not been built yet.

06 · DESIGN PATTERN

Repository Pattern

I plan to investigate the Repository Pattern. This approach separates database operations from the rest of the application.

For example, the website could use a task repository to create, update, delete, and retrieve tasks instead of placing database code throughout the interface.

This pattern is being researched and has not yet been implemented.

07 · CREATIVE EXPERIMENT

Testing Two Dashboard Designs

Basic Task List

A simple list showing assignments and whether they are complete.

Priority & Deadline Dashboard

A dashboard that organizes tasks by priority, due date, and completion status.

My experiment will compare which design makes it easier for students to understand what they should work on next. This experiment is planned, not yet tested.
